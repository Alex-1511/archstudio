# AI Agent Architecture
Ten agents (Design, Drawing Interpretation, CAD Generation, BIM, Computational, Facade, Rendering, Critic, Integration, Memory) share one **structured project context** and act only via the **tool layer** (`archcore/tools.py`).
**Implemented:** `LLMProvider` abstraction; `GeminiProvider` (untested); `FakeProvider`; `plan_tool_calls` (model output → validated tool calls, rejects hallucinated tools, supports `ask_user` instead of inventing dimensions); tool permissions (`read`/`write`); all writes undoable; failures roll back.
**Added in v0.2:** per-tool argument schemas (types, ranges, unknown keys rejected) enforced for every caller; all-or-nothing batches with `$N.id` references; a clarification loop (`converse`) that executes nothing while a question is open and feeds project context (ids) to the model. **Still a skeleton:** no multi-agent routing, no multimodal drawing input, no architectural reasoning beyond what the model supplies.
**Rules:** (1) the model never emits vertices; (2) missing dimension → ask or flag uncertainty; (3) the Critic separates measurable issues (computed from geometry) from subjective critique; (4) render enhancement may not add architectural elements.
**Planned:** orchestrator routing, multimodal drawing interpretation with per-element confidence, RAG memory tiers (global / user / project / Architect Inspire / accepted-rejected suggestions) with user-controlled export/delete. No claim of model retraining: personalisation = retrieval + preference profile.
